# SkillPatch API

SkillPatch is an Academy Operations Platform designed to centralize certification management, employee development programs, learning initiatives, and Academy operational workflows.

## Current Status

This project is currently under development as part of a Software Engineering academic project.

## Tech Stack

- Python
- Flask
- SQLite
- Git

## Features

- User authentication (planned)
- Employee management
- Certification management
- Campaign management
- Dashboard and reporting
